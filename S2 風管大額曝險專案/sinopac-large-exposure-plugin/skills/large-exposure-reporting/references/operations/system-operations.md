# 大額暴險系統操作流程

## 常用流程

### 查詢集團與客戶資料

1. 先以集團資料查詢確認既有集團與成員。
2. 再以客戶主檔查詢確認統一編號、名稱與歸屬集團。
3. 必要時匯出同一關係企業名單，或使用外部資料來源交叉查核。

### 新增尚未歸戶的客戶

1. 若尚無可用集團代碼，先建立集團主檔。
2. 再建立客戶主檔與集團對應。
3. 客戶資料可逐筆建立或批次上傳。
4. 集團代碼格式為一碼英文字母加六碼數字；前綴對應存在來源衝突，應依目前核准清單辦理。

### 每月交易資料上傳

1. 進入「永豐雲／內部控制／金控大額暴險系統管理／交易明細檔維護作業」。
2. 選擇資料上傳單位及公司或部門。
3. 執行客戶交易檔匯入。
4. 檢視檢核結果；若出現無效集團代碼，先修正主檔或對應資料，再重新上傳。
5. 完成檢核後執行批次放行。

## 操作紀錄代碼

| 代碼 | 功能 |
|---|---|
| `RF0001` | 上傳與放行 |
| `RF2001` | 集團主檔維護 |
| `RF2002` | 客戶主檔維護 |
| `RF2003` | 客戶差異資料 |
| `RF2004` | 交易明細維護 |
| `RF2005` | 交易資料放行 |
| `RF2006` | 淨值資料維護 |
| `RF2007` | 大額暴險名單擷取 |
| `RF2104` | 交易明細檢核 |
| `RF3001` | 集團暴險查詢 |
| `RF9001` | 使用者維護 |
