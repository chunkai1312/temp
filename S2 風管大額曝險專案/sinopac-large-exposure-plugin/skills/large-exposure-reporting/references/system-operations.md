# 大額暴險系統功能與操作畫面

## 第 2 頁 金控集團資料查詢

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 金控集團檔維護作業。

點選左側「金控集團維護作業」，查詢完成後可在線上瀏覽或匯出。

範例：若要查詢金控集團名稱包含「塑」的集團，可在金控集團名稱輸入「塑」，按下查詢後逐筆瀏覽；若要整批查詢，按下查詢後下載旁邊的 Excel 檔案。

## 第 3 頁 金控集團客戶資料查詢

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 客戶主檔維護作業。

可點選查詢進行線上瀏覽，也可點選匯出資料。

範例：若要查詢金控集團名稱為台塑的客戶，可在客戶主檔維護作業的金控集團名稱輸入「台塑」，按下查詢在線上瀏覽，或再按下匯出資料，整批匯出屬於台塑集團的客戶對照。

## 第 4 頁 每月申報集團客戶名單

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 客戶主檔維護作業。

每月製作大額暴險申報資料時，可在客戶主檔維護作業的交易對象項目選取「同一關係企業」，日期留白，再點選查詢及匯出資料。

## 第 5 頁 外部集團資料查詢

外部資料來源：TEJ 資料庫。

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 客戶主檔維護作業 → 外部資料查詢。

範例：若要查詢外部資料庫中「聯華」相關公司的 TEJ 集團歸屬名稱，可在外部資料查詢的客戶中文名稱輸入「聯華」，點選查詢後查看 TEJ 對應集團名稱。

## 第 6 頁 功能維護

新往來客戶若在大額暴險系統尚無對應集團，應先新增集團代號，再建立客戶資料。

### 第一步 新增集團代號

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 金控集團檔維護作業 → 點選「＋」新增集團代碼 → 在資料維護中填寫金控集團代碼及金控集團名稱。

新增集團編碼邏輯為「英文字母一碼＋數字六碼」，由各單位逕行編號：

| 子公司 | 範例 |
|---|---|
| 銀行子公司 | `B001234` |
| 證券子公司 | `L123456` |
| 租賃子公司 | `S123456` |
| 創投子公司 | `V123456` |
| 永豐銀行（中國） | `N123456` |
| 京城子公司 | `K123456` |

### 第二步 新增集團客戶資料

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 客戶主檔維護作業。

可逐筆建立或整批上傳：

1. 逐筆建立：在下方資料維護中點選「＋」新增客戶，輸入客戶統編、客戶中文或英文名稱、金控集團代碼及金控集團名稱。
2. 整批上傳：在「客戶主檔匯入」中選取要整批上傳的客戶資料。

## 第 7 頁 每月交易資料上傳

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 交易明細檔維護作業 → 選擇資料上傳單位 → 選擇所屬公司及部門 → 客戶交易檔匯入 → 上傳資料檢核。

上傳完畢後，確認系統出現成功訊息並核對資料筆數。

若檢核出現「無效集團代碼」，應到「金控集團檔維護作業」確認是否已有該集團；若無，須新增集團後重新上傳。

## 第 8 頁 交易明細檔放行

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 交易明細檔放行作業 → 選擇交易資料區間 → 整批放行。

## 第 9 頁 資料維護紀錄查詢

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 資料維護紀錄查詢 → 選擇維護時間區間 → 查詢。

可查詢資料修改及異動情況。

## 第 10 頁 作業紀錄查詢

路徑：永豐雲 → 內部控制 → 金控大額暴險管理 → 作業紀錄查詢。

| 功能代號 | 功能內容 |
|---|---|
| `RF0001` | 交易上傳及放行紀錄 |
| `RF2001` | 金控集團檔維護作業 |
| `RF2002` | 客戶主檔維護作業 |
| `RF2003` | 客戶差異檔維護作業 |
| `RF2004` | 交易明細檔維護作業 |
| `RF2005` | 交易明細檔放行作業 |
| `RF2006` | 金控淨值檔維護作業 |
| `RF2007` | 擷取企審大額名單 |
| `RF2104` | 交易明細檢核 |
| `RF3001` | 金控整體暴險狀況查詢 |
| `RF9001` | 使用者維護作業 |
