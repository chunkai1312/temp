# F19／表十九規則

## 用途、頻率與單位

- 銀行財務作業中心、證券、租賃及京城銀行原則上於每月 `10` 日前上傳前 `40` 大資料，使用 `F19－前40大（Top40）.xls`。
- 各子公司依風險管理處提供的名單上傳前 `30` 大交易資料，使用 `F19－前30大（Top30）.xls`。
- 風險管理處彙整前 `40` 大資料形成前 `30` 大名單，並原則上於每月 `15` 日前完成申報。
- 金額單位為新臺幣千元。

## 交易項目與金額欄位

| 代碼 | 交易項目 | 填報基礎 |
|---|---|---|
| `02` | 放款 | 當月最高餘額 |
| `04` | 有價證券購買或投資 | 當月最高餘額 |
| `05` | 不動產或其他資產買賣 | 本年累積交易總額 |
| `06` | 資本租賃交易 | 當月最高餘額 |
| `07` | 手續費、佣金及服務費收入 | 本年累積交易總額 |
| `08` | 租金收支 | 本年累積交易總額 |
| `09` | 存出及存入保證金 | 當月最高餘額 |
| `10` | 捐贈 | 本年累積交易總額 |
| `11` | 保證及背書 | 當月最高餘額 |
| `12` | 其他交易 | 當月最高餘額 |

放款包括存單質押借款、保單質借及證券融資。有價證券購買或投資包括債券、票券、股票、受益憑證及其他有價證券的買斷、賣斷與附條件交易。

## 最高餘額

本版依既有測試預期，將「當月最高餘額」解釋為該交易項目在當月申報期間內曾出現的最高餘額，而非月底餘額或單筆最高交易額。

正式規範原文只列示欄位名稱「當月最高餘額或本年累積交易總額」，尚未提供更完整的計算定義，因此正式上線前須由風險管理處確認。詳見 `KB-CONFLICT-001`。

## 常見錯誤

- 將所有項目都填最高餘額。代碼 `05`、`07`、`08`、`10` 應填本年累積交易總額。
- 用表七的代碼 `41` 至 `45` 回答表十九問題。
- 遺漏新臺幣千元的金額單位。
- 將「當月最高餘額」誤答成「月底帳列餘額」。
