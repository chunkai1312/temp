# A07／表七規則

## 用途與單位

| 使用情境 | 檔案或表單 | 金額單位 |
|---|---|---|
| 子公司每月上傳金控大額暴險系統 | `表七－交易上傳格式.xlsx` | 新臺幣元 |
| 金控彙整後對外申報 | A07 | 新臺幣千元；比率欄為百分比 |

不得看到「表七」就一律回答新臺幣千元；必須先確認使用者是在問子公司內部上傳檔，還是金控對外 A07 表格。

## 主要交易代碼

| 代碼 | 交易項目 |
|---|---|
| `10` | 授信，不含短期票券之保證或背書 |
| `11` | 授信－無擔保金額 |
| `12` | 授信－有擔保金額 |
| `21` | 短期票券之保證或背書－無擔保金額 |
| `22` | 短期票券之保證或背書－有擔保金額 |
| `31` | 附賣回交易－票券，包括一年以內之受益證券及資產基礎證券 |
| `32` | 附賣回交易－公債 |
| `33` | 附賣回交易－公司債券及金融債券 |
| `34` | 附賣回交易－其他有價證券 |
| `41` | 投資或購買有價證券－票券，包括一年以內之受益證券及資產基礎證券 |
| `42` | 投資或購買有價證券－公司債券及金融債券 |
| `43` | 投資或購買有價證券－與股權相關之有價證券 |
| `44` | 投資或購買有價證券－證券化商品 |
| `45` | 投資或購買有價證券－其他有價證券 |
| `51` | 債券衍生性商品交易 |
| `52` | 利率衍生性商品交易 |
| `53` | 資產交換交易 |
| `54` | 結構型商品交易 |
| `55` | 股權衍生性商品交易 |

| `57` | 外匯衍生性商品交易 |

| `61` | 其他經主管機關規定－證券化商品資產池連結之暴險 |
| `62` | 其他經主管機關規定－衍生性契約可能承受標的資產之名目本金暴險 |

## 與表十九的關係

同一客戶、同一業務別在表七與表十九原則上金額應一致，但表十九另有交易類別與「當月最高餘額或本年累積交易總額」欄位。使用者問表十九時，不得直接引用本表代碼作答。
