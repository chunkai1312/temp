辦理利害關係人授信以外交易之檢核
⚫ 查詢時機：
✓ 辦理授信外交易前查詢，並留存查詢紀錄
✓ 簽核流程審核通過後，簽約前再次查詢，並留存查詢紀錄
⚫ 查詢對象：
✓ 交易對象
✓ 交易參與者
✓ 對交易對象具控制力之「最終受益人」(以公文系統或實體簽呈提案者)
⚫ 交易類型(金融控股公司法 第45條第2項)：
✓ 投資或購買前項各款對象為發行人之有價證券
✓ 購買前項各款對象之不動產或其他資產
✓ 出售有價證券、不動產或其他資產予前項各款對象
✓ 與前項各款對象簽訂給付金錢或提供勞務之契約
✓ 前項各款對象擔任金融控股公司或其子公司之代理人、經紀人或提供其他收取佣金或費用之服務行為
✓ 與前項各款對象有利害關係之第三人進行交易或與第三人進行有前項各款對象參與之交易。

## 第 16 頁

16
辦理利害關係人授信以外交易之檢核
⚫ 交易條件：不得優於其他同類對象，並留存佐證資料
比價方式：
➢ 原則：逐筆檢附「交易條件未優於同類對象」證明文件，如：與其他非利害關係人之報價、同業報價、公開價格資訊、其他非利
害關係人提供同等服務之收費標準、交易雙方與第三人進行類似交易之交易條件等；若確實無同類對象可供比較時，得提出交易
價格業經獨立評估合理性之證明文件。
➢ 例外：
1. 已由經理部門評估價格合理性之下列交易，得免逐筆檢附「交易條件未優於同類對象」之證明文件：
1) 單筆金額未超過新臺幣壹萬元之小額交易。
2) 具一致性收費標準且無法議價之公共交通費(如高鐵)、電信網路費、公用事業費交易。
3) 與金控母公司之證券子公司、保險子公司間之即期外匯交易，交易條件應符合市場實務且不偏離銀行間即期外匯市場價格。
2. 與永豐金控或金控100%持股之子公司間因共用設備、共同舉辦活動、共同贊助或其他原因，而與非利害關係人辦理共同採購，
單筆契約總金額未超過新臺幣伍百萬元，得自行依實際分攤比率(如：使用人數、使用量、獲得之對價、營業規模、客戶數..等)說
明分攤金額合理性，作為「交易條件未優於同類對象」之證明。
★ 金管會 110年度上半年主要檢查缺失(金控)
缺失情節：子公司間進行授信以外交易，提報子公司董事會審議時未說明同類對象報價及比價情形，逕以會計師
出具價格合理意見書認定交易條件並未優於其他同類對象。
