| 交易判斷 | 問題2-1：永豐金控採購永豐金證券發行的股票禮品卡，作為本次股東會紀念品，採購金額預估超過5000萬，請問請購及採購前需執行甚麼程序？ | 規範摘要：依據金管會112.12.07金管銀法字第11202738872號令，除涉及股權性質之有價證券交易外，金融控股公司與其直接或間接持股百分之百之子公司及該直接或間接持股百分之百子公司間單筆交易金額未超過新台幣伍千萬元之交易。 / 操作步驟： / 1.因採購金額超過5,000萬，超過概括授權金額，故永豐金控及永豐金證券應分別提報董事會重度決議。(無需提報審計委員會) / 2.股票禮品卡目前為永豐金證券獨家商品，市面上確無其他同類對象可供比價，故應請會計師出具價格合理意見書。 / 文件引用段落：金融科技發展與創新實驗條例第9條、金管銀法字第11202738872號令。 |

|  | 問題2-2：永豐金證券經營股權交換、股權選擇權及結構型商品等店頭衍生型金融商品業務，基於客戶需求買賣金融控股公司法第45條所定利害關係人為發行人之有價證券，需經董事會重度決議還是得以董事會概括授權方式辦理？ | 規範摘要：依據金管會114.12.02金管銀法字第1140237725號函，證券商經營股權交換、股權選擇權及結構型商品等店頭衍生性金融商品業務，基於客戶需求買賣金融控股公司法第45條所定利害關係人為發行人之有價證券，得以董事會概括授權方式辦理。 / 注意事項/限制條件：金融控股公司之證券子公司依財團法人中華民國證券櫃檯買賣中心證券商營業處所經營衍生性金融商品交易業務規則經營股權交換、股權選擇權及結構型商品等店頭衍生性金融商品業務，上開商品連結之有價證券發行人於契約期間成為金融控股公司法第45條所定利害關係人之情形，證券子公司基於客戶提前解約、履約與到期結算之需求，賣出或買回金融控股公司法第45條所定利害關係人為發行人之有價證券，得經董事會重度決議概括授權經理部門依內部作業規範辦理，視同符合金融控股公司法第45條第1項規定。 / 文件引用段落：金管銀法字第1140237725號函。 |

|  | 問題2-3：金控公司之子公司與金融控股公司法第45條所列對象辦理辦理涉及主動式交易所交易基金之交易，需經董事會重度決議還是得以董事會概括授權方式辦理？ | 規範摘要：依據金管會114.6.20金管銀法字第1140213639號函，金融控股公司之子公司與金融控股公司法第45條所列對象辦理下列授信以外交易，得依金管會112.12.7金管銀法字第11202738872號令「金融控股公司法第45條釋疑」第一點規定，經董事會重度決議概括授權經理部門依內部作業規範辦理： 1.投資、處分金控法第45條所列對象發行之主動式交易所交易基金，且經理部門應逐筆彙整成交紀錄及其損益情形，按季提報董事會備查。 / 2.證券子公司擔任主動式交易所交易基金之參與證券商，因執行主動式交易所交易基金之實物申購/買回機制而投資或購買金控法第45條所列對象為發行人之有價證券。 / 3.證券子公司擔任主動式交易所交易基金之流動量提供者，其為報價及應買應賣義務，而於集中交易市場、櫃檯買賣市場所為之交易。 / 4.證券子公司辦理定期定額業務，以調節專戶買賣金控法第45條所定利害關係人發行之主動式交易所交易基金，且經理部門就該調節專戶逐筆彙整交易紀錄及損益情形，按季提報董事會備查。 / 文件引用段落：金管銀法字第1140213639號函。 |

|  | 問題2-4：金控之子公司辦理臺灣期貨交易所店頭衍生性金融商品集中結算業務，是否適用金融控股公司法第45條規定？ | 規範摘要：依據金管會112.11.22金管銀法字第1120274090號函，金融控股公司之子公司擔任期交所店頭衍生性金融商品集中結算業務一般結算會員，為屬該子公司利害關係人之客戶提交衍生性金融商品之交易契約，於期交所辦理集中結算，因約務更替而成立之結算契約，與原交易契約之交易條件相同，且該結算契約係為進行集中結算所需，與交易契約之性質不同；另提供集中結算服務所收取之費用，係公開之收費標準收取，旨揭交易尚非屬金融控股公司法第45條規定之目的範疇，得不適用該條規定。 / 文件引用段落：金管銀法字第1120274090號函。 |
