|  | 問題2-5：捐贈給利害關係人的程序 | 規範摘要： / 外規：依據金管會100.04.18金管銀法字第10000070800號函，金融控股公司或其子公司對利害關係人辦理授信以外之交易時，應依金融控股公司法第45條及其相關規定辦理。有關「捐贈」於金融控股公司法第45條適用一節，考量捐贈為無償性，無「不優於同類對象」條件之適用；但辦理捐贈，須依據公司治理實務守則，制訂相關內部規範送董事會決議，並對政黨、利害關係人及公益團體所為之捐贈情形對外公開揭露。另依據臺灣證券交易所股份有限公司對有價證券上市公司重大訊息之查證暨公開處理程序第四條第一項第四十三款及第六條第一項第一款規定，依「公開發行公司董事會議事辦法」規定，辦理對關係人之捐贈屬於上市公司重大訊息，應於事實發生日起次一營業日交易時間開始二小時前輸入。 / 內規：依據利害關係人授信及交易政策暨管理辦法第四條規定，填寫利害關係人授信以外交易檢核表，由單位法遵主管簽核，併依捐贈管理辦法第六條規定，本公司及各子公司對政黨、利害關係人及公益團體所為之捐贈情形，應定期對外公開揭露。另依據辦理重大訊息公告準則第七條規定辦理。 / 操作步驟： / 留存查詢交易對象及參與者之紀錄，另確認對交易對象具控制力之最終受益人是否為利害關係人，查詢紀錄應留存備查。 / 填寫利害關係人授信以外交易檢核表。 / 提報審委會及董事會。 / 辦理重大訊息公告作業。 / 文件引用段落：金管會100.04.18金管銀法字第10000070800號函 |

|  | 問題2-6：金控之證券子公司經營自行買賣業務，買進非利害關係人之有價證券，而後該標的轉為利害關係人，應如何處理？ | 規範摘要：依據金管會101.02.10金管銀法字第10000455940號函，金融控股公司之證券子公司經營自行買賣業務，買賣涉及股權性質之有價證券，買進時該標的公司非利害關係人，嗣後轉為利害關係人時，公司內部分層負責之權責單位應依金融控股公司法第45條規定及金管會100.02.22金管銀法字第10000002220號函辦理。惟於2次董事會期間，該標的轉為利害關係人且損失達公司風險控管之停損標準者，為減少損失，得依公司董事會通過之風控準則停損標準先行賣出，再補報下次董事會同意。 / 注意事項/限制條件： / 提報董事會重度決議。 / 文件引用段落：金管會101.02.10金管銀法字第10000455940號函。 |

|  | 問題2-7：金控之證券子公司以信託方式辦理財富管理業務對信託財產不具運用決定權者，買賣利害關係人所發行之有價證券，是否為金控法第45條之規範範圍？ | 規範摘要：依據金管會100.08.26金管銀法字第10000243790號函，兼營信託業務之證券子公司(受託人)以信託方式辦理財富管理業務對信託財產不具運用決定權者，依委託人指示買賣金融控股公司第45條所定利害關係人發行之有價證券，得不受同條文第1項有關應經公司三分之二以上董事出席及出席董事四分之三以上之決議後為之規定之限制；惟金融控股公司或其子公司以信託方式指示受託人，買賣金融控股公司法第45條所定利害關係人發行之有價證券，仍應受同條文規定之限制。 / 文件引用段落：金管會100.08.26金管銀法字第10000243790號函。 |
