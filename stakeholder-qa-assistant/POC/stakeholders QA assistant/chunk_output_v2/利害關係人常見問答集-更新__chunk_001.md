# 利害關係人常見問答集-更新

金控利害關係人常見問答集

| 問題類型 | 項目 | 答案 |

| --- | --- | --- |

| 利害關係人類型/名單範圍 | 問題1-1：銀行公會通知永豐銀行董事被選為這屆的理事，是否需要建檔銀行公會是利害關係人？ | 規範摘要：參酌金管會101年4月26日金管銀法字第10100115910號函釋，如章程已明訂以董事長為對外代表人，依民法第27條第2項之除外規定，該法人之其餘董事(含獨立董事)，非屬於銀行法、金控法所稱之代表人。 / 注意事項/限制條件： / 銀行公會是依「商業團體法」成立的組織，以「理事長」為對外代表人。如果董事未擔任銀行公會的理事長，則不具對外代表權，銀行公會就不是董事擔任代表人的團體，無須申報。 / 文件引用段落：金控法第45條第1項第2款、金管銀法字第10300304490號函。 |

|  | 問題1-2：金控董事去當東海大學的董事，是否需要建檔東海大學為利害關係人? | 規範摘要：參酌金管會101年4月26日金管銀法字第10100115910號函釋，如章程已明訂以董事長為對外代表人，依民法第27條第2項之除外規定，該法人之其餘董事(含獨立董事)，非屬於銀行法、金控法所稱之代表人。 / 注意事項/限制條件： / 依據東海大學捐助章程，董事長對外代表該財團法人。金控董事未擔任東海大學的董事長，則不具對外代表權，無須申報。 / 文件引用段落：金控法第45條第1項第2款、金管銀法字第10300304490號函。 |

|  | 問題1-3：永豐金投信發行之開放型基金，是否需要依金控法第45條建檔為實質關係人？ | 規範摘要：依會計研究發展基金會114年6月16日發布「關係人之認定疑義」IFRS問答集，對於國內證券投資信託事業依現行有關法令及證券投資契約所經理之公開募集共同基金，不再辨認為關係人。其他類型基金請逐檔依IFRS問答集內容判斷是否為實質關係人，並留存書面評估記錄。 / 操作步驟：經判斷屬於實質關係人之基金，應至金控利害關係人管理系統建檔為實質關係人。 / 注意事項/限制條件： / 依會計研究發展基金會最新發布問答集114年06月16日 IAS 24關係人之認定疑義，應判斷投信對該基金有無控制、重大影響或提供主要管理人員之服務。 / 文件引用段落：會計研究發展基金會114年6月16日IAS 24「關係人之認定疑義」問答集 |

|  | 問題1-4：銀行或金融控股公司負責人，以非股東之專家身分擔任公司制證券交易所之董事或監察人者，是否有銀行法第33條之1暨金融控股公司法第44條、第45條規定之適用？ | 規範摘要：依據金管會101.08.14金管銀法字第10100220400號函，銀行負責人、辦理授信之職員或銀行法第33條之1第1款有利害關係者，或金融控股公司之負責任及大股東，依證券交易法第126條第2項規定，以非股東之專家身分擔任公司制證券交易所之董事或監察人，則該公司制證券交易所非屬銀行法第33條之1第4款規定所稱之利害關係人，亦非屬金融控股公司法第44條第2款及第45條第1項第2款所稱擔任負責任之企業。惟上開人員非依證券交易法第126條第2項規定擔任公司制證券交易所之董事或監察人，則該公司制證券交易所仍屬前開規定所稱利害關係人及擔任負責任之企業。 / 文件引用段落：金管銀法字第10100220400號函。 |
