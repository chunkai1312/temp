「疑似申報關係異常」資料檢視

- 系統自動偵測符合下列疑似申報異常邏輯，將定期寄送提醒郵件及永豐雲系統待辦，通知申報人進行申報資料之確認。

(一)金控及子公司(除銀行外)

| 系統邏輯 |  |
| --- | --- |
| 邏輯一 | 直接關係人未申報任何親屬 |
| 邏輯二 | 直接關係人僅申報一血資料，但無申報任何二血資料 |
| 邏輯三 | 直接關係人僅申報二血資料，但無申報任何一血資料 |

(二)銀行

| 系統邏輯 |  |
| --- | --- |
| 邏輯一 | 直接關係人僅申報血親資料，但無申報任何姻親資料 |
| 邏輯二 | 直接關係人僅申報二血資料，但無申報任何三血資料 |
| 邏輯三 | 直接關係人僅申報三血資料，但無申報任何二血資料 |
| 邏輯四 | 直接關係人僅申報配偶資料，但無申報任何姻親資料 |
| 邏輯五 | 直接關係人未申報任何親屬 |
| 邏輯六 | 經理人/經理人職代/核委未完整申報父或母(一血) |
| 邏輯七 | 經理人/經理人職代/核委有配偶卻未完整申報配偶之父或母(一姻) |

- 系統操作方式：

1.請進入本系統首頁之最新法規及待辦，點選關係人每月檢視資料/疑似申報關係異常之「選擇」鈕。

2.請依系統顯示邏輯檢視您於系統內所申報的資料是否完整，如有漏申報或需調整資料時，應盡速辦理補正。

3.完成系統檢視及資料補正作業後，請返回『申報親屬關係檢核』頁面，並勾選欲回報之選項(序號)。

4.依實際情形選擇回覆說明。如選擇『08-其他』選項者，請於後面備註欄位敘明原因。

5.填寫完畢，請送出。
