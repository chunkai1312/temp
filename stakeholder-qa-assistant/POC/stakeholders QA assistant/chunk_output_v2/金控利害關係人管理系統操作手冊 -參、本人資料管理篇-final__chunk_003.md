回復申報資料

- 申報人如欲與「曾經有申報但現況已解除」之親屬或相關事業建立利害關係，得使用「回復申報資料」功能取代逐筆建檔。

- 請於申報人主檔畫面點選「關係資料/回復申報資料」進入功能畫面：

- 「回復申報資料」功能畫面說明如下：

「曾經申報資料源」：選取曾有申報資料之建檔公司/身分別。

「擬回復申報資料之目前有效身分」：選取現欲辦理建檔之建檔公司/身分別。

「查詢」：顯示上述曾經申報過但現已解除的親屬及相關事業。

請勾選擬回復的資料並調整為正確生效日後，按「確認回復」。

若擬回復的資料生效日均相同，請勾選後，按「同一生效日整批回復」並輸入正確生效日期，即可執行整批資料回復。

複製申報資料

- 本人如具有多種有效身分(如：同時為銀行經理人及銀行核貸委員、同時為金控經理人及證券董事)，得使用「複製申報資料」功能複製生效中的申報資料，取代逐筆建檔。

- 請於本人主檔畫面點選「關係資料/複製申報資料」進入功能畫面：

- 「複製申報資料」功能畫面說明如下：

「複製源頭」：選取生效中申報資料的建檔公司/身分別。

「複製到」：選取擬將上述資料複製到的何者建檔公司/身分。

「確認」。

檢視所有關係

一、本人可點選「關係資料/檢視所有關係」檢視所申報之相關資料，並得點選

「資料匯出」產出excel報表。

二、「檢視所有關係」畫面及各欄位說明如下：

（一）查詢條件：可依「關係狀態」(有效/預約生效/解除/預約解除) 、「關係

公司」或「身分」等條件進行查詢，如不選取條件則為全部查詢。

（二）關係資料：將依查詢條件顯示關係資料。

（三）資料匯出：可選擇依查詢條件匯出資料。

資料調整

本人得自行維護調整(修改)已建檔之親屬/相關事業資料之關係別、相關事業擔任職務類型；其餘項目（如：名稱、證號、國籍、生效日期、解除日期等）之調整，請洽各公司權責單位。

調整生效中之親屬關係別/相關事業擔任職務類型

請於「本人資料管理」頁面「關係資料/親屬及相關事業」選取擬調整之親屬/相關事業並按下「編輯」鈕，即可進入該筆資料調整「關係別」或「事業擔任職務」。

解除資料

- 請於「本人資料管理」頁面下方「關係資料/親屬及相關事業」選取擬解除之親屬/相關事業並按下「解除」鈕，即可進入該筆資料進行解除。

- 「解除」功能畫面說明如下：

「狀態」：說明如下表：

| 日期 | 請選擇： |  |
| --- | --- | --- |
| 解除日期在作業(維護)日 | 後 | 8-預約解除 |
|  | 前/當日 | 9-解除 |

「解除日期」：請點選解除日期。

「關係解除原因」：請依實際狀況點選。如點選「07-其他」，請於「備註」欄位說明。

「更新」：相關欄位資料填寫完成後，點選「更新」完成資料解除作業。

更正已解除資料之關係別

- 請進入「資料管理/本人更正已解除資料關係別」功能調整已解除之利害關係人「關係別」。

- 「更正已解除資料關係別」功能畫面說明如下：

「查詢」：請點選查詢後顯示查詢結果。

請於查詢結果點選擬調整資料左方之「選擇」鈕，進行關係別調整。

定期檢視作業

每月檢視資料作業

- 每月一日系統自動寄送通知郵件及永豐雲待辦（永豐雲待辦清單申請稽核/法遵/風險利害關係人）通知申報人進行資料之檢視確認。

- 檢視方式：

1.請進入系統首頁點選「關係人每月檢視資料/每月資料檢視」之「選擇」鈕。

2.請確實檢視【資料顯示】之內容是否正確無需異動。

※應檢視本人身分、所申報之關係人資料(含證號、名稱、關係名稱、生效日) 是否完整及正確。

※如於同一公司或不同公司具有多重身分(例如：同時為銀行經理人兼核貸委員、金控經理人兼銀行經理人...等)，應逐一檢視不同身分別均有完整及正確申報親屬及相關事業
