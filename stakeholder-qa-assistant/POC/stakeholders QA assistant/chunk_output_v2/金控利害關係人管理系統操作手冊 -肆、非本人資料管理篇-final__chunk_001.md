# 金控利害關係人管理系統操作手冊 -肆、非本人資料管理篇-final

> Source: 金控利害關係人管理系統操作手冊 -肆、非本人資料管理篇-final.docx

金控利害關係人管理系統操作手冊

《肆、非本人資料管理篇》

制定單位：法令遵循處

制定日期：2021.12.○

非本人資料管理

一、本系統設有防火牆，具有「各公司關係人維護窗口」權限者，得利用「非本人資料管理」相關功能，建檔及維護所屬公司申報人應申報之利害關係人資料，如董、監事、大股東、經理人、核貸委員及親屬或事業資料。

二、進入系統方式：

【方法一】永豐雲 → 內部控制/法令遵循 → 金控利害關係人管理 → 資料管

理/非本人資料管理。

【方法二】永豐雲 → 待辦清單 → 申請 → 稽核/法遵/風險 → 利害關係人

→資料管理/非本人資料管理。

資料建檔

建立主檔

一、利害關係人管理系統內「建檔資料」(即主檔)，包含申報人、親屬、相關事業..等利害關係人之主檔為各公司共用。金控及其子公司之經理人、核貸委員、銀行職員的主檔資料，系統自動與金控或各公司人力資源系統連結，毋須另以人工方式建檔，其餘身分(如：董監事、大股東…等)則需以人工方式建立主檔。

二、建立主檔之方式有兩種，①以「新增關係人」之方式直接建立主檔、②利用「新增親屬/新增相關事業」的方式同時建立主檔及關係檔;本項將先介紹第一種方式，第二種方式及應注意事項，詳第三、四項之說明。

三、操作說明：

（一）請先以「資料查詢」確認擬建檔之資料是否已存在於本系統，如曾於本系統建檔，請直接進入主檔進行其他相關功能操作。

（二）如查詢無相關資料，請開始新增關係人主檔：

「性質別」：請於下拉式選單進行選擇。

「00-建檔公司」：指金控或其子公司。

「01-自然人」：新增自然人。

「02-法人」：新增法人。

點選「新增關係人」進入主檔建檔資料畫面。

（三）主檔之建檔資料畫面說明如下：

「中文名稱」/「英文名稱」：請輸入中文/英文名稱。

「所屬公司」/「所屬單位」：請依下拉式選單選取。

「員工編號」：如為法人或非員工，無需填寫。

「主要證號」：請輸入主要證號。若暫無法取得主證號，請點選「主證號取號」，並於取得真正證號後進行調整。

「主要證號國別」：請輸入所屬國別。

「生效日期」：請點選成為利害關係人之日期。

「送審」：送審至覆核主管進行覆核。

新增「本人身分」

一、建立主檔與「建檔公司」之關係(即取得本人身分)：

系統內所建檔之主檔，需與建檔公司(即金控與金控之各子、孫公司)連結關係後(取得本人身分)，始成為申報人，能進行後續新增親屬/新增相關事業等關係人資料申報作業。

「經理人、銀行職員、核貸委員」等本人身分，由系統自動與金控及各子公司人力資源系統/授信核決權限系統進行連結，毋須另以人工方式建立與建檔公司之關係，其餘本人身分(如：董監事、大股東…等)則需另以人工方式建立關係。

二、建立本人身分的方式

進入主檔資料畫面後，點選「新增關係」，連結與「建檔公司」之關係。

三、「新增關係」之功能操作說明：

「選擇關係對象」：輸入「證號」或「名稱」，按下查詢後，選取擬新增關係之對象。

「關係類別」：建立與建檔公司(即金控或其子、孫公司)之關係，關係類別應選擇「01-本人」。(即取得本人身分)

「關係別」：請依下拉式選單選擇。

「關係生效日期」：點選成為金控或其子、孫公司利害關係人之日期。

狀態：說明如下表：

| 日期 | 請選擇： |  |
| --- | --- | --- |
| 關係生效日期在建檔日 | 前/當日 | 0-有效 |
|  | 後 | 1-預約生效 |

「送審」：送審至覆核主管進行覆核。

- 如同時擔任多間公司之關係人維護窗口，需注意「建檔公司」應與「關係對象中文名稱」相同(即應為同一間公司)，否則系統無法送審(會出現建檔方式錯誤訊息)。

四、建檔完成(覆核主管放行後)之畫面(範例)：

新增親屬

一、以「新增親屬」方式辦理建檔，將同時建立親屬的主檔並連結本人與親屬的關係，故請先以「資料查詢」確認擬建檔之親屬於系統無建檔，如該親屬曾於系統建檔，應直接以「新增關係」方式辦理關係資料連結。
